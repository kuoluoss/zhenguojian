# 真果鉴

多站源短剧浏览与在线播放应用，Android 手机版。基于开源项目 [Topkill/guoapp3](https://github.com/Topkill/guoapp3) 二次开发与改版。

当前版本：**0.7.18+78** ｜ 平台：Android 8.0+（arm64-v8a） ｜ [下载最新版](https://github.com/kuoluoss/zhenguojian/releases/latest)

---

## 一、这是什么

一款聚合多个短剧站源的客户端：浏览、搜索、详情、选集、在线播放、下载与合并，**全部在手机本地完成**，不依赖任何自建服务器或中转。

- **站源解析**：设备端直接请求各站源接口，不经过第三方中转。
- **数据存储**：剧库、追剧、观看历史、下载记录都保存在本机。
- **账号**：没有云端账号，不需要登录；只有本机用户与权限管理。

## 三、快速开始

1. 从 [Releases](https://github.com/kuoluoss/zhenguojian/releases/latest) 下载 `zhenguojian-<版本>-arm64-v8a.apk`。
2. 手机上安装（需允许「安装未知来源应用」）。
3. 打开即用；之后有新版本时，App 内会提示更新。

要求：**Android 8.0 及以上、64 位（arm64-v8a）**。
若安装提示 `INSTALL_FAILED_NO_MATCHING_ABIS`，表示设备架构与安装包不匹配。

## 五、手势速查

### 竖屏（手机）

| 操作 | 效果 |
| --- | --- |

| 操作 | 效果 |
| --- | --- |
| 左右滑动 | 调整进度（拖动时显示目标时间，松手生效） |
| 左侧 1/3 上下滑 | 画面亮度 |
| 右侧 1/3 上下滑 | 音量 |

## 七、常见问题

**Q：为什么剧库更新要很久？**
A：更新需要逐部复查详情。红果 2600 多部约 11 分钟、黄果 AI 2200 多部约 18 分钟，而单轮上限 10 分钟，所以会分批续跑。0.7.1 已把后台自动更新改为 2 小时间隔、可关闭；手动更新仍可随时执行。

**Q：黄果几个源有时更新失败？**
A：属网络可达性问题，不是解析错误 —— 黄果视频走 IPv6 且无备用域名，黄果 AI 的镜像域名会被重置。换网络或开代理后重试通常能恢复。

**Q：调了亮度，手机屏幕亮度没变？**
A：设计如此。只调整视频画面亮度，不动系统亮度，退出播放器后手机亮度不受影响。

**Q：为什么只提供 64 位安装包？**
A：目标设备（手机与投影仪）均为 arm64。32 位构建脚本保留，但不再发版。

**Q：支持电视 / 电脑吗？**
A：Android TV 适配已暂停（遥控导航能力随老播放器一并移除，日后重新实现）；Windows 版源码保留但当前不构建、不交付。

**Q：需要登录吗？**
A：不需要。没有云端账号；本机用户管理只用于区分不同使用者与权限。

## 十、开发与构建

环境：Flutter `3.47.4`、Dart `3.12+`、Go `1.24.1+`、Python `3.10+`；Android 需 JDK 17、SDK 36、NDK `28.2.13676358`。

```sh
# 全站源版（真果鉴）
python3 scripts/build_android.py --abi arm64-v8a --all-sources
# 仅红果版（红果鉴）
python3 scripts/build_android.py --abi arm64-v8a
```

- **必须在纯英文路径下构建**（中文路径会导致工具链失败）。
- 构建时不要设 HTTP 代理；访问 GitHub 时才需要代理。
- 产物在 `dist/android/`，`SHA256SUMS.txt` 为校验清单。

源码结构：

| 目录 | 内容 |
| --- | --- |
| `lib/` | 页面、播放器、本地用户、FFI、下载与媒体处理 |
| `native/core/`、`native/bridge/` | Go 站源核心、缓存、下载与 C ABI |
| `android/`、`windows/`、`ios/` | 平台工程与必要资源 |
| `scripts/`、`.github/workflows/` | 构建、签名、验证与版本快照 |
| `test/`、`integration_test/` | 自动化与设备回归 |

仓库只提交业务源码，不包含构建产物、依赖缓存、本地机器配置、签名文件与任何密钥。

播放器使用 [media_kit](https://github.com/media-kit/media-kit) / libmpv，合并与导出使用 [FFmpegKit min-gpl](https://github.com/sk3llo/ffmpeg_kit_flutter)（含 FFmpeg、x264 / x265 等 GPL 组件，适用上游许可证）。
